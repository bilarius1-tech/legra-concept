# ЛЕГРА — премиум-концепт сайта (лестницы на заказ, Саратов)

Живой макет для согласования с клиентом перед сборкой на Тильде (Zero Block).
Статичный сайт: plain HTML/CSS/JS, библиотеки с CDN — GSAP 3.12 + ScrollTrigger (cdnjs), Lenis (unpkg), шрифты Google Fonts (Cormorant Garamond + Manrope).

Источник контента — старый сайт legramaster.ru (копия на https://legra.vaybik.ru): тексты, телефон, адрес, фото, логотип. Ничего не выдумано; характеристики в карточках разобраны из исходных подписей к фото.

## Палитра и стиль
| Токен | Цвет | Где |
|---|---|---|
| `--brown-900` | `#120a07` | основной фон (сплошной на всю страницу) |
| `--black` | `#0b0705` | прелоадер, глубина |
| `--beige` | `#e3cfb2` | текст, заголовки |
| `--beige-2` | `#c9b08e` | курсив в заголовках |
| `--red` | `#ca0f00` | акцент (цвет из логотипа): кнопки, линии, подсветка |

Фон один на всю страницу (`.bg`, `position:fixed`): мягкие медленно плывущие пятна коричневого/тёмно-красного + зерно (SVG-noise). **Никаких полос светлый/тёмный между блоками.**

## Доступность / производительность
- `prefers-reduced-motion`: отключаются плавный скролл, прелоадер, автоплей, параллакс, зерно; бегущая лента становится сеткой; FLIP — мгновенное открытие.
- Фото: webp, работы ≤1400 px (24–85 КБ), герой 1900 px (146 КБ). Всё медиа ~0,8 МБ.
- Адаптив: десктоп / планшет (≤1100) / мобильный (≤820). Бургер-меню, свайп в галерее.
- Если CDN не загрузился — контент виден, просто без анимаций.
- `noindex` — это макет.
