# ЛЕГРА — премиум-концепт сайта (лестницы на заказ, Саратов)

Живой макет для согласования с клиентом перед сборкой на Тильде (Zero Block).
Статичный сайт: plain HTML/CSS/JS, библиотеки с CDN — GSAP 3.12 + ScrollTrigger (cdnjs), Lenis (unpkg), шрифты Google Fonts (Cormorant Garamond + Manrope).

Источник контента — старый сайт legramaster.ru (копия на https://legra.vaybik.ru): тексты, телефон, адрес, фото, логотип. Ничего не выдумано; характеристики в карточках разобраны из исходных подписей к фото.

## Калькулятор (блок 4в)
Файлы: `css/calc.css`, `js/calc-config.js` (все цены и списки), `js/calc.js`; для Тильды — собранный `tilda/calc-t123.html` (пересобрать: `python3 tools/build-tilda-calc.py [URL папки img/calc]`).

**Откуда логика и цены.** Старый «Калькулятор лестниц» (index.php + js/common.js) **стоимость не считал**: он собирал выбор клиента (тип, основание, материал ступеней и ограждений, высота и ширина) и отправлял заявку менеджеру («Что бы узнать точную стоимость — отправьте заявку»). Формул и цен лестниц там нет. Единственные цены на старом сайте — каталог балясин (₽/шт); они перенесены точно, сверены с живой страницей (30 позиций, 0 расхождений; у «Грибок», «Симметрия», «Точеная» цены нет → «по запросу»). У поручней и мебельных щитов цен на старом сайте нет — в расчёт не включены.

**Что считает.** Геометрия по высоте этажа: число ступеней = округление (высота / 175 мм) с коррекцией в норму 150–200 мм, высота ступени, угол, оценка удобства по формуле 2h+b (600–640 мм). Итог «от N ₽» = только позиции с ценой (сейчас балясины × количество); ступени и ограждение показываются в разбивке как «по замеру». Чтобы включить их в расчёт, достаточно вписать числа вместо `null` в `prices.stepPerPiece` / `prices.railingPerMeter` (+ необязательные `typeFactor`, `foundationFactor`) — формула уже заложена: ступени = число ступеней × цена × коэффициенты; ограждение = длина × цена за метр.

**Форма «Отправить расчёт»** — демо: проверяет поля, показывает «Спасибо», ничего не отправляет. В Тильде: поставить рядом нативный блок формы Тильды (ZERO-форма/BF) с полями имя, телефон, чекбокс согласия и скрытым полем «расчёт» (текст разбивки) — либо в `calc.js` в обработчике `submit` подключить `tildaForm`/webhook. Добавить ссылку на политику обработки ПДн рядом с чекбоксом.

Якорь меню «Калькулятор» в Тильде: перед вставкой поставить блок «Якорная ссылка» с именем `calc` (в собранном файле уже есть `<a name="calc">`).

## Доступность / производительность
- `prefers-reduced-motion`: отключаются плавный скролл, прелоадер, автоплей, параллакс, зерно; бегущая лента становится сеткой; FLIP — мгновенное открытие.
- Фото: webp, работы ≤1400 px (24–85 КБ), герой 1900 px (146 КБ). Всё медиа ~0,8 МБ.
- Адаптив: десктоп / планшет (≤1100) / мобильный (≤820). Бургер-меню, свайп в галерее.
- Если CDN не загрузился — контент виден, просто без анимаций.
- `noindex` — это макет.
